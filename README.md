# Dannita XV

Página web estática lista para GitHub Pages.

## Publicarla
1. Crea un repositorio en GitHub.
2. Sube **todos los archivos y la carpeta `assets`** de este proyecto.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub Pages publique la página.

El archivo principal es `index.html`. No cambies la ubicación de `assets` ni borres sus archivos.
